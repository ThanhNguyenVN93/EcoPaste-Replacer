🚀 Introducing EcoPaste Replacer — swap Windows Clipboard History for EcoPaste in one click!

Do you use Win+V every day but wish it had more features? EcoPaste Replacer will:

✅ Disable Windows' built-in Clipboard History
✅ Automatically install EcoPaste (if missing) — a free, open-source clipboard manager
✅ Apply a ready-to-use config, launch it, and enable auto-start on login
✅ All with a single click — no manual setup needed

Free and open-source, works on Windows 10/11.
